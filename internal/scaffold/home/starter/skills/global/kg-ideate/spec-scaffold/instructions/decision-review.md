# Decision Review — Phase 2 Step 5

Rules for Phase 2 prior decision review:

- Present each prior_decision with its source (KGNote ID or §C proposal ID) and rationale.
- Ask one of: "Does this still apply?", "Does this need to be revisited?", "Is this
  out of scope for the new spec?"
- If user says revisit: add it to open_questions in the spec, not decisions.
- If user says out of scope: note it as a deferred item.
- If no prior decisions exist: skip this step and say so explicitly.
