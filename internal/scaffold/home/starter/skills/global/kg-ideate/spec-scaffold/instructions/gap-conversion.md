# Gap Conversion — Phase 2 Step 6

Rules for Phase 2 gap → open question conversion:

- Each gap from the briefing becomes a candidate open question in the form:
  "How should the new spec handle X, given that the KG has no prior decision on it?"
- Present all gaps at once (not one-by-one) to reduce interaction overhead.
- User selects which to include; unselected gaps are not added to the spec.
- Open questions in the spec must be phrased as questions the plan will answer, not
  as design decisions. (Design decisions belong in the decisions section of the spec.)
- An open question that the briefing already answers mechanically is a signal the work may
  qualify for concurrent/folded spec↔plan mode (Phase 3 step 10).
