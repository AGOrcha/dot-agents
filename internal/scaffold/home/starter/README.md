# ~/.agents/

Managed by [dot-agents](https://github.com/NikashPrakash/dot-agents).

## Canonical Buckets

### Stage 1
- `rules/` for reusable instructions and constraints
- `settings/` for platform settings and current Cursor ignore support
- `mcp/` for MCP server definitions
- `skills/` for reusable skills and prompt workflows
- `agents/` for reusable subagents and personas
- `hooks/` for automation hooks
- `context/` for local workflow checkpoint state
- `resources/` for backups and restore state

### Stage 2 scaffold
- `ignore/` for cursorignore / cursorindexingignore files
