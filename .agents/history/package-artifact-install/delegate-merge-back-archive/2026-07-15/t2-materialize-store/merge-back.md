## Summary

Third pass — closes the 3 remaining safety/correctness HIGH from the t2 re-review (CRITICAL H13 + H14/H15/H16 already confirmed fixed). FIX 1 (concurrency isolation): the prior rework used a package-global projection context (currentUnits, guarded by projectionSerialize/unitsMu — the SetWindowsMirrorContext pattern) that the builders read; a concurrent plain RunSharedTargetProjectionExact (existing refresh/install callers, not routed through the serialize lock) could read ANOTHER project's units and project repoA's package into repoB. ELIMINATED the global entirely: ProjectResolvedUnits now threads the resolved units as pure invocation-local data straight into buildCASIntents (a parameter), and merges local-authored + CAS-direct intents into one plan itself rather than relying on the builders to read shared state. The builders (buildSharedMirrorIntentsForRoot) reverted to local-authored-only and never touch packages data. Per-platform dir-mirror roots are derived deterministically via sharedDirMirrorRoots (a type-switch mirroring each platform's SharedTargetIntents dir-mirror roots) + unionDirMirrorRoots, so CAS projection still works for empty buckets and projects with no local sibling — WITHOUT any global or filesystem-scan for authority. FIX 2 (H17 foreign-symlink + fallback): atomicManagedSymlinkSwap now replaces ONLY an identity-verified managed link whose resolved target is under managed CAS storage (config.ArtifactsRoot) — a foreign user symlink (pointing outside) or any real dir/file is left completely intact and the call fails closed; the links.Symlink (RemoveAll-after-check) fallback was REMOVED so an un-creatable temp symlink also fails closed, never reaching a RemoveAll. FIX 3 (one-to-zero prune): reducing a bucket from one unit to zero previously emitted no prune-target intent so the dir was never scanned and the stale link survived forever; ProjectResolvedUnits now forces the deterministic per-platform dir-mirror bucket roots into the prune scan (new plan.pruneStaleSharedTargetsExtraDirs) so the bucket dir is scanned regardless of the desired set — the removed unit's managed link is pruned even with no local sibling. One fail-before-fix test each, each independently verified to FAIL on a reverted fix (simulated global → cross-contamination; neutered identity check → foreign symlink replaced; nil extra prune dirs → link survives) and PASS after. Full go test ./... green; config+platform+links green under -race; fsguard/importguard/gofmt clean.
