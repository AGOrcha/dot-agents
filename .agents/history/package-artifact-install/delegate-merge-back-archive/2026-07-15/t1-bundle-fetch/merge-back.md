## Summary

Final normalizer round — two same-class fixes, both in internal/config. (1) Gitlink error-path bypass (fetcher_git_artifact.go): when the committed-tree lookup errored, tree stayed nil and rejectGitSubmodules returned success, so a directory artifact bypassed the submodule check and the pinning-defeat returned. cloneAndResolve now propagates the tree-resolution error via a treeErr return; a directory artifact fails closed (ReasonContent) when the committed tree is unresolvable; and rejectGitSubmodules treats a nil tree as a hard error (defense in depth). Single-file artifacts still ignore treeErr (they need no tree). (2) OCI cache-read bound + identity (fetcher_oci.go): readCachedArtifact used an unbounded, symlink-following os.ReadFile that fully allocated (or followed a symlink to) an arbitrary file before digest verification. New readConfinedCacheBlob opens an os.Root on the packages cache and applies the local-path discipline — no-follow Lstat rejecting a symlinked/non-regular entry, over-cap size rejection before opening, os.SameFile fd-identity check, io.LimitReader(MaxFileBytes+1) before hashing. One fail-before-fix regression test each (TestGitArtifactFetcherDirectoryRejectsUnresolvableTree, TestReadConfinedCacheBlobRejectsOversized, TestReadCachedArtifactRejectsSymlinkedCacheEntry); a probe confirmed the old symlink-following read would have served a substituted target.

## Integration Notes

cloneAndResolve signature now returns (wfs, tree, treeErr, commit, err) — internal to the git fetcher, no cross-task surface change. The normalized Bundle contract and BundleLimits are unchanged from the prior round. All confirmed-good invariants from prior rounds (PAX bomb, symlink TOCTOU, OCI digest-format, local-root escape, path-form/digest/torn-cache) unchanged. Full suite + race green; coverage ~96-97%.
