# Lessons index

One line per lesson. See each `LESSON.md` for the full pattern, root
cause, rule, and how-to-apply.

- [`hermetic-env-for-cli-probe-tests`](./hermetic-env-for-cli-probe-tests/LESSON.md): Unit tests that drive CLI-detection code must pin a hermetic base PATH in package `TestMain` (toolchain + system dirs, minus the agent-CLI dirs) — inheriting the real PATH leaks real `--version` subprocesses, a machine-dependent gate timeout invisible on CI.
- [`worktree-sibling-path-buildvcs`](./worktree-sibling-path-buildvcs/LESSON.md): Worktrees at sibling paths outside the repo root break `go build` VCS stamping in the pre-push gate — keep worktrees under the repo (e.g. `.agents/worktrees/`) or pass `-buildvcs=false` deliberately.
- [`tests-for-each-slice`](./tests-for-each-slice/LESSON.md): Each implementation slice should add automated coverage for the behavior it introduces before the slice is considered complete.
- [`additive-state-fields`](./additive-state-fields/LESSON.md): When extending a central state struct, add a new field rather than reusing an existing one — keeps JSON contract stable and callers unbroken.
- [`test-string-count-ids`](./test-string-count-ids/LESSON.md): When checking for duplicate entries in a markdown index, count `"- [id]"` (the entry prefix) not the raw ID string — the ID can appear multiple times in a single valid link entry.
- [`kg-test-fixture-helper`](./kg-test-fixture-helper/LESSON.md): KG tests needing a populated graph should use `setupKGWithNotes(t)` — don't re-seed notes inline per test.
- [`test-stub-upgrade-pattern`](./test-stub-upgrade-pattern/LESSON.md): When upgrading a stub to a real implementation, grep for tests asserting stub side-effects and update them before running the full suite.
- [`refresh-import-before-relink`](./refresh-import-before-relink/LESSON.md): Refresh flows that import repo files and regenerate managed outputs must import project content before relinking, and must not replay canonical backup snapshots as live state.
- [`verify-managed-file-target`](./verify-managed-file-target/LESSON.md): When a task touches a managed file path, use the intended managed generation flow first; if a repo-local file is still required, verify the final path is not a generated managed link before closing the task.
- [`use-skill-architect-for-skill-generation`](./use-skill-architect-for-skill-generation/LESSON.md): When generating or restructuring skills, use the skill-architect workflow so skills are valid before they are treated as usable or promoted to managed resources.
- [`archive-completed-active-plans`](./archive-completed-active-plans/LESSON.md): When a plan is complete, move it out of `.agents/active/` into the matching history folder so the active set reflects current work instead of finished tasks.
- [`lint-check-count-assertion`](./lint-check-count-assertion/LESSON.md): When adding a new lint check, grep for `ChecksRun` count assertions in tests and update them to `N+1` before running the suite.
- [`sidecar-manifest-pattern`](./sidecar-manifest-pattern/LESSON.md): Store integrity hashes in a sidecar manifest file keyed by ID, not inline in the file being hashed — avoids self-referential hash problem.
- [`rfc-resolves-plan`](./rfc-resolves-plan/LESSON.md): Plans gated on "requires RFC" often already contain the answers — write a brief RFC and implement in the same session instead of spending a full cycle on research.
- [`analysis-gaps-need-tasks`](./analysis-gaps-need-tasks/LESSON.md): When a session produces analysis results (A/B comparisons, gap findings, identified bugs), those findings must become canonical tasks before the session closes — prose notes are not tasks and don't get scheduled.
- [`select-star-scan-order`](./select-star-scan-order/LESSON.md): When porting DB schemas to Go, SELECT * scans must match exact column order — enumerate columns explicitly or count and comment them inline.
- [`use-existing-subdir-helpers`](./use-existing-subdir-helpers/LESSON.md): In kg.go, use `noteSubdir(t)` not `noteType+"s"` — "entity" maps to "entities" not "entitys".
- [`symbol-only-references-in-artifacts`](./symbol-only-references-in-artifacts/LESSON.md): Workflow artifacts reference code by symbol/function/relational anchor — never line numbers. Line numbers drift the instant any sibling edit lands.
- [`test-file-naming`](test-file-naming/LESSON.md) — test files mirror source/feature; iteration-numbered grab-bag test files (`coverage_pushN`, `ci_driftN`, …) are forbidden.
- [`subagent-out-of-workspace-access`](subagent-out-of-workspace-access/LESSON.md) — spawned subagents are sandboxed to the workspace root; pre-authorize external dirs or read inline.
- [`stale-local-master-ref`](stale-local-master-ref/LESSON.md) — audits must verify against origin/<branch>, not the stale local ref (caused a 3-way cascade).
- [`concurrent-workers-one-worktree`](concurrent-workers-one-worktree/LESSON.md) — one active writer per worktree; workers must not self-arm CI waiters (orchestrator polls + relays).
- [`prefer-interface-di-over-funcvar-seams`](prefer-interface-di-over-funcvar-seams/LESSON.md) — interface-DI is the preferred test seam; func-var `var osX = os.X` is legacy; prevalence ≠ sanctioned (audits must state descriptive vs prescriptive).
- [`match-ci-test-flags-locally`](match-ci-test-flags-locally/LESSON.md) — verify concurrency changes with CI's exact flags (`-race -count=1`) before push; lazy WaitGroup.Add needs mutex+closed ordering vs Wait.
- [`credstore-loader-test-hangs-on-macos-keychain`](credstore-loader-test-hangs-on-macos-keychain/LESSON.md) — a unit test that drives a real `credstore.NewLoader()` resolution passes on linux/windows but TIMES OUT on the macOS CI shard (the keyring step blocks on the macOS Security Service on a headless runner). Assert fallback wiring by TYPE (`_, ok := r.(*credstore.Loader)`), or exercise the chain hermetically with `WithKeyring(nil)` + `DA_CREDENTIALS_FILE` — never resolve through the real keychain in a test.
- [`cf-worker-auth-gate-fail-closed`](cf-worker-auth-gate-fail-closed/LESSON.md) — fail-closed checklist for auth-gating a Cloudflare Worker + static-assets (from an adversarial review of the docs CF Access gate): static assets BYPASS the worker unless `run_worker_first: true` (the per-route array misses bare `/internal` + encoded variants); classify paths fail-closed after decode+normalize (`/internal%2f..`, `/INTERNAL`, `//internal`, dot-segments, NUL all gate); allowlist public files, never carve out a whole dir (a blanket `/schemas/*` leaked internal DTO schemas); attach bearer-equivalent headers HTTPS-ONLY (refuse before resolving the secret); hand-rolled JWT must pin RS256/reject none+HS, require non-empty kid, kty=RSA, enforce exp/nbf/iss/aud, fail closed on every error. Verify with a Miniflare real-runtime smoke (`routerConfig.invoke_user_worker_ahead_of_assets`), not a stubbed-binding unit test or `serve dist` (both bypass the worker).
- [`validate-bundle-against-head`](validate-bundle-against-head/LESSON.md) — TASKS.yaml status/notes/write_scope decay between snapshots; HEAD-validate write_scope paths AND task premise before `workflow fanout`, especially after history rewrites.
- [`worker-owns-pr-readiness-loop`](worker-owns-pr-readiness-loop/LESSON.md) — loop-workers self-monitor + auto-fix CI/Sonar issues until PR is review-ready; parent context only sees terminal READY or FOLD-BACK.
- [`verify-task-status-vs-pr-history`](verify-task-status-vs-pr-history/LESSON.md) — pre-fanout: cross-check `gh pr list --state merged --search <task-id>` and dependent-task statuses; TASKS.yaml lies after parallel waves. `delegation closeout --decision accept` auto-advances; `workflow advance` is for direct (non-delegated) work.
- [`loop-worker-vs-general-purpose`](loop-worker-vs-general-purpose/LESSON.md) — loop-worker needs a delegation bundle; use general-purpose subagent for ad-hoc PR-shipping work without a canonical task.
- [`starter-vs-project-overlay`](starter-vs-project-overlay/LESSON.md) — generic starter ships how-to-USE `da` (the product); dot-agents dev overlay holds how-to-DEVELOP dot-agents (gh, /tmp/dev binary, Sonar gates).
- [`no-lazy-allowlist-tech-debt`](no-lazy-allowlist-tech-debt/LESSON.md) — coverage-exceptions.txt entries without a scheduled cg6 task are silent regression of the 95% gate; "not my work" needs scope+plan+schedule.
- [`parallel-worker-branch-drift`](parallel-worker-branch-drift/LESSON.md) — prek pre-commit hooks can land a worker's commit on a sibling worktree's branch via stash/restore; verify branch HEAD matches worker's claimed commit post-push.
- [`bundle-scope-via-code-graph`](bundle-scope-via-code-graph/LESSON.md) — pre-flight write_scope with `mcp__code-review-graph__file_summary` + grep for unexported symbols before `workflow fanout`.
- [`worktree-no-cd`](worktree-no-cd/LESSON.md) — multi-worktree sessions: always `git -C <path>` and never `cd` (Bash pwd persists across calls and cross-wires worktree state).
- [`init-bypasses-hooks-package`](init-bypasses-hooks-package/LESSON.md) — `commands/init.go` writes Claude/Cursor global settings/hooks directly; should route through the hooks package + restore settings+hooks merging.
- [`const-extraction-triggers-cpd-on-tables`](const-extraction-triggers-cpd-on-tables/LESSON.md) — fixing S1192 dup literals via const extraction can trigger Sonar CPD when the literal sits inside a tabular layout; data-driven refactor (loop over typed slice) is required.
- [`sonar-rating-gate-misses-new-issues`](sonar-rating-gate-misses-new-issues/LESSON.md) — SonarCloud's "Sonar way" gate is rating-based; doesn't fail on individual CRITICAL smells if rating stays A; must add custom gate with new_violations > 0 → FAIL; agent-side pr-ci-watch verifier independently checks count.
- [`verifier-owns-ci-watch-shift-left`](verifier-owns-ci-watch-shift-left/LESSON.md) — for dot-agents project overlay: register a `pr-ci` verifier_profile (alongside `unit`/`api`/`batch`) in .agentsrc.json + author the prompt file. Existing global `verifier` agent owns gh+Sonar polling per the profile; auto-fixes mechanical issues, escalates non-mechanical to impl. Impl exits at merge-back. Audit at .agents/proposals/pr-ci-verifier-integration-audit.md.
- [`agents-lack-autonomous-timers`](agents-lack-autonomous-timers/LESSON.md) — Claude Code agents have no autonomous timer; "every Ns" charter language silently fails. v1: piggyback on every incoming message. v2: workflow-orchestrator-daemon owns the scheduler.
- [`venv-symlink-into-worktrees-pre-adapter`](venv-symlink-into-worktrees-pre-adapter/LESSON.md) — symlink the repo `.venv` into every new worktree before push hooks fire; pre-push coverage-gate runs `go test ./...` which transitively needs CRG's Python venv. Expires when graph-backend-adapter-contract lands.
- [`consolidate-vestigial-siblings-on-rename`](consolidate-vestigial-siblings-on-rename/LESSON.md) — a "rename/generalize this primitive" request usually means "consolidate the duplication around it"; audit for duplicate-shaped fields + superseded-but-not-retired surfaces (and their lagging consumers) before planning, instead of scoping to the literal rename.
- [`merge-back-frontmatter-required`](merge-back-frontmatter-required/LESSON.md) — `da workflow delegation closeout` rejects merge-back artifacts missing any schema_version=1 frontmatter field; `files_changed:` MUST be `[]` or block-list. Silent rejection on first hit.
- [`dep-routing-on-partial-start-signals`](dep-routing-on-partial-start-signals/LESSON.md) — user "start X (since Y is …)" means "make X eligible per dep routing," not "force-spawn now." Verify Y ≥ awaiting_owner_review before fanout; else queue X as blocked-on:Y per layered-pr-fanout §3.4.
- [`stale-local-checkout-mass-drift`](stale-local-checkout-mass-drift/LESSON.md) — a local checkout many commits behind origin accumulates spurious working-tree deletions + mixed dirty state; `da`/`eligible` then read stale plans. Recovery: backup-branch the dirty tree, hard-sync local to origin/master, re-apply genuinely-local-only authored docs. Sibling of [[stale-local-master-ref]].
- [`ssh-keepalive-for-slow-pre-push-hook`](ssh-keepalive-for-slow-pre-push-hook/LESSON.md) — push fails `Connection ... closed by remote host` AFTER green hooks because the slow pre-push hook (sonar-scanner etc.) idles the SSH connection past GitHub's timeout. Fix: `GIT_SSH_COMMAND="ssh -o ServerAliveInterval=15 -o ServerAliveCountMax=30"` — never `--no-verify`. Always verify the ref landed with `git ls-remote`.
- [`sonarcloud-gate-mechanics`](sonarcloud-gate-mechanics/LESSON.md) — free-tier SonarCloud has no branch analysis (local scanner evaluates working-tree-as-main → keep main green); editing a file resurfaces its old issues as new-code; fixes can trade findings (`ADD --chown`→S6504, `wget --https-only`≠disable-redirects, `--ignore-scripts` may break builds); CE "Task finished abnormally" is a retryable infra flake; execabs deprecated (Go 1.19+) so go:S4036 PATH probes are reviewed-safe. Sibling of [[ssh-keepalive-for-slow-pre-push-hook]].
- [`sonar-mcp-security-filter-under-reports`](sonar-mcp-security-filter-under-reports/LESSON.md) — when `new_security_rating>A` fails the gate but the Sonar MCP `impactSoftwareQualities=SECURITY` query returns 0 issues, it is usually NOT a flake: the MCP impact filter omits legacy `type=VULNERABILITY` findings (e.g. `githubactions:S6505/S8543/S8233`). Query the API directly with `types=VULNERABILITY` (BUG/CODE_SMELL for the other ratings) BEFORE concluding flake, then fix (e.g. `npx`→`npm exec --no`, workflow→job permissions) — no suppressions.
- [`proactively-apply-built-capabilities`](proactively-apply-built-capabilities/LESSON.md) — after creating/improving a skill/agent/audit capability, proactively RUN it on the live project (dogfood immediately), don't build-and-move-on. "We just built X" is the trigger to "now run X and route its output." Evidence: the release-docs-refresh audit matrix, once finally run, found drift in 4/6 categories in one parallel sweep.
- [`leverage-cross-platform-fs-helpers`](leverage-cross-platform-fs-helpers/LESSON.md) — route OS-divergent fs behavior through `internal/fsops` (mutations) and `internal/testutil.MakeDir/FileUnreadable` (forced access errors); never branch on `runtime.GOOS` or use the NTFS-ignored `0o000` trick — single-OS-green hides Windows-red.
- [`worktree-isolation-defeats-status-tracking`](worktree-isolation-defeats-status-tracking/LESSON.md) — workers in isolated worktrees update task status in their own worktree, invisible to the main-repo scout → re-dispatch storms (5×duplicate PRs). Fan-out scouts must exclude open-PR tasks + keep a cross-wave dispatched-set; null-guard the scout; the real fix is a shared coordination backend.
- [`pin-release-toolchain-and-make-releases-retryable`](pin-release-toolchain-and-make-releases-retryable/LESSON.md) — pin every build/signing/timestamp tool to an exact version (never `--prerelease`/unpinned; an unpinned signing tool caused the Linux `kernel32`/`DLSequence` crash) + add a CI guard that fails on unpinned installs; make releases idempotent (delete the stale tag + `workflow_dispatch` re-drive on infra failure, don't poison on tag-exists). Sibling of [[gates-must-be-locally-reproducible]].
- [`hermetic-home-for-state-resolving-tests`](hermetic-home-for-state-resolving-tests/LESSON.md) — any test that resolves `$HOME`/graph-home/state-dir/platform-dirs/keychain MUST `t.Setenv` an isolated `t.TempDir()` env (HOME/USERPROFILE/XDG_*) so it resolves only paths it created; root cause of the flaky `TestRunWorkflowPlanDeriveScopeDegradesGracefully` that forced `--no-verify`. Generalizes [[credstore-loader-test-hangs-on-macos-keychain]]; PATH sibling [[hermetic-env-for-cli-probe-tests]].
- [`gates-must-be-locally-reproducible`](gates-must-be-locally-reproducible/LESSON.md) — if a CI gate (Sonar etc.) isn't locally reproducible, fix THAT (hermetic exclusions for `dist/`/`.scannerwork`, a runnable local invocation, install the hook) instead of CI-round-tripping or bypassing with `--no-verify`; the sonar dist/.scannerwork flake drove the bypasses. Sibling of [[sonar-container-fsmonitor-socket]], [[sonarcloud-gate-mechanics]].
